## 类型转换
使用 `static_cast` 进行类型转换，示例：
```cpp
int a = 1;
double b = static_cast<double>(a);
```

## 常量和字符串
尽量使用 `const` 和 `constexpr` 来定义常量和字符串，而不是使用 `#define` 。
定义全局常量，使用 `inline` 来定义，通常在头文件中定义。
```cpp
// 头文件中定义
inline constexpr  int MAX_VALUE = 100;
```
### string
可以使用`std::getline`来读取一行字符串，示例：
```cpp
std::string line;
std::getline(std::cin >> std::ws, line); // 读取一行字符串，忽略前导空格
```

使用`.length()`来获取字符串长度。同时作为函数参数时，不要按值传递，而是按引用传递。

对于只读的字符串，使用`std::string_view`来传递，可以减少拷贝，提高性能。

## 内联命名空间 
内联命名空间`inline namespace`可以用来版本管理，将命名空间内的内容直接暴露出来，而不是通过命名空间来访问。
```cpp
inline namespace v1 {
    void foo() {
        std::cout << "v1" << std::endl;
    }
}

int main() {
    foo(); // 直接调用foo函数
    return 0;
}
```

## 控制流

### switch 的 [[fallthrough]]
使用 `[[fallthrough]]` 来表示 switch 的 fallthrough，表明该 case 会 fallthrough 到下一个 case。

### random
使用梅森旋转算法来生成随机数，示例：
```cpp
unsigned seed = 114514;//也可以使用 std::random_device{}() 来生成种子
std::mt19937 gen(seed);
std::uniform_int_distribution<int> dist(1, 100);// 生成1到100之间的随机数
int random_number = dist(gen);
```

## 错误处理
使用断言来处理错误，包含在`<cassert>`头文件中。
```cpp
assert(condition);
```
可以和错误消息相与，示例：
```cpp
assert(condition && "Error message");
```

使用异常来处理错误，包含在`<exception>`头文件中。
```cpp
throw exception;
```
同时尽量使用`static_assert`来处理错误，示例：
```cpp
static_assert(condition, "Error message");
```


也可以和错误消息相与，示例：
```cpp
throw std::runtime_error("Error message");
```

### auto

要想推断出 `string`类型，需要显示加上`s`:
```cpp
auto s = "string";
```
### 函数指针
使用 `using` 来定义函数指针，示例：
```cpp
#include <string>
#include <string_view>

int main()
{
    using namespace std::literals; // easiest way to access the s and sv suffixes

    auto s1 { "goo"s };  // "goo"s is a std::string literal, so s1 will be deduced as a std::string
    auto s2 { "moo"sv }; // "moo"sv is a std::string_view literal, so s2 will be deduced as a std::string_view

    return 0;
}
```

## 重载与模板
### 模板
将函数使用模板编写分为两步：
1. 将变量替换为类型模板参数（T 或者 ...）
2. 将函数替换为函数模板

示例：
```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

在`C++20`中，可以使用`auto`来推断类型，示例：
```cpp
template <typename T>
auto add(T a, T b) -> std::common_type_t<T, T> {
    return a + b;
}
//等价于
auto add(auto a, auto b) {
    return a + b;
}
```

非类型模板参数： 是一个具有固定类型的模板参数，它作为占位符，用于替换传递作为模板参数的 constexpr 值

示例：
```cpp
#include <iostream>

template <int N> // declare a non-type template parameter of type int named N
void print()
{
    std::cout << N << '\n'; // use value of N here
}

int main()
{
    print<5>(); // 5 is our non-type template argument

    return 0;
}
```

## 引用与指针
### 引用
在函数调用中，使用引用可以避免拷贝，提高性能。
```cpp
void foo(int& a) {
    a = 10;
}
int main() {
    int a = 1;
    foo(a);
    return 0;
}
### 指针
空指针：`nullptr`
使用 `const` 来修饰指针，可以指向常量。
在使用auto推导指针时，优先使用`auto*`
```cpp
int main() {
    int x = 10;
    int* ptr_x = &x;

    // `auto` 推导指针
    auto c = ptr_x; // c 被推导为 int*

    // `auto*` 推导指针
    auto* d = ptr_x; // d 被推导为 int*

    // `auto*` 的强制性
    auto* e = x; // 编译错误！
                 // e 被强制为指针类型，但 x (int) 不是一个指针
}
```
### std::optional
使用 `std::optional` 来处理可能为空的情况，示例：
```cpp
#include <iostream>
#include <vector>
#include <optional> // 1. 包含头文件

// 2. 返回一个 std::optional<int>
// 这能清楚地表明函数可能返回一个 int，也可能什么都不返回
std::optional<int> find_index_optional(const std::vector<int>& vec, int value_to_find) {
    for (int i = 0; i < vec.size(); ++i) {
        if (vec[i] == value_to_find) {
            return i; // 找到，返回包含值的 optional (自动构造)
        }
    }
    // 3. 返回一个"无值"的 optional
    return std::nullopt; // std::nullopt 是 "无值" 的常量
}

int main() {
    std::vector<int> data = {10, 20, 30, 40};

    // 案例 1: 查找存在的值
    std::optional<int> result1 = find_index_optional(data, 30);

    // 4. 检查它是否包含值 (非常方便直观)
    if (result1.has_value()) {
    // 也可以简写为: if (result1) {
        // 5. 使用 .value() 或 * 来安全访问值
        std::cout << "Optional 法 (找到): 索引在 " << result1.value() << std::endl;
        // 也可以写为: std::cout << *result1 << std::endl;
    } else {
        std::cout << "Optional 法 (未找到)" << std::endl;
    }

    // 案例 2: 查找不存在的值
    std::optional<int> result2 = find_index_optional(data, 99);
    if (result2) { // 使用简写形式
        std::cout << "Optional 法 (找到): 索引在 " << *result2 << std::endl;
    } else {
        std::cout << "Optional 法 (未找到)" << std::endl;
    }
}
```


## 枚举和结构体
结构体中可以使用模板，示例：
```cpp
template <typename T>
struct MyStruct {
    T value;
};
MyStruct<int> my_struct;
my_struct.value = 1;
```
